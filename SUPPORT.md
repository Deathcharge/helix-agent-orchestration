# Support

Samsarix Orchestration is an alpha open-source project maintained by Samsarix LLC.

- Search existing [issues](https://github.com/Deathcharge/samsarix-agent-orchestration/issues)
  before opening a reproducible bug report or focused feature request.
- For installation, usage, and compatibility questions, email support@samsarix.com.
- For general, licensing, or commercial questions, email contact@samsarix.com.
- Report suspected vulnerabilities privately using the instructions in
  [SECURITY.md](SECURITY.md), not in a public issue.

Include the package version, Python version, operating system, smallest reproducible example,
expected behavior, and actual behavior. Remove credentials, personal data, proprietary
workflow inputs, and other secrets from reports.

Support is best effort unless a separate written agreement applies. No public response-time,
resolution-time, or compatibility commitment is implied.
